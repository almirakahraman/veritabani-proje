# Veritabanı Projesi

Bu proje, veritabanı şeması ve ilgili dosyaları içerir.

## Dosyalar

- `veritabanı_sema.sql`: Veritabanı şeması tanımı.

## Kurulum

1. SQL dosyasını veritabanı yönetim sisteminize yükleyin (örneğin MySQL, PostgreSQL).
2. Şemayı çalıştırarak tabloları oluşturun.

## Kullanım

Veritabanı şemasını kullanarak uygulamanızı geliştirin.

## Katkıda Bulunma

Pull request'ler kabul edilir.

## Lisans

Bu proje açık kaynaklıdır.
